Flight Data Analysis with Hadoop & Oozie | AWS-based Distributed System

Read More

Designed and implemented a distributed data processing workflow using Hadoop and Apache Oozie to analyze over 20 years of U.S. flight data (~100M+ records). Developed and orchestrated multiple MapReduce jobs to identify top-performing airlines, analyze airport taxi times, and determine common flight cancellation reasons. Deployed the solution on AWS EC2 instances, performed scalability testing across varying VM counts, and benchmarked performance over incremental time spans. Demonstrated strong skills in big data processing, cluster configuration, and workflow automation.

Read More

Achieved 73% classification accuracy, demonstrating the potential of quantum-inspired models in text classification tasks within the biomedical domain.

Equity Portfolio Management Strategy Simulation

Read More

Simulated a $5 million equity portfolio using 2018 daily stock data from 10 major tech companies. Implemented and compared two rebalancing strategies—buying the lowest vs. highest performers every 5 business days—while accounting for dividends and FX impact (USD/JPY). Tracked daily portfolio value (MTM), benchmarked against a custom high-tech index, and analyzed performance to find the optimal rebalancing frequency.

Sarcasm Detection Using Transformer Models

Read More

Developed a sarcasm detection model using Transformer-based architecture to tackle the growing challenge of identifying sarcasm in online text. The project involved extensive data preprocessing, text cleaning, and the construction of a custom Transformer encoder incorporating Multi-Head Attention, positional encoding, and feedforward layers. By capturing nuanced contextual dependencies in language, the model achieved high accuracy and precision in distinguishing sarcastic from non-sarcastic content. Performance was evaluated using average precision score, accuracy, and confusion matrix, demonstrating the model's effectiveness in handling the complexities of sarcastic expressions.
